# Zero Trust Architecture Lab

[🇧🇷 Português](#-português) | [🇬🇧 English](#-english)

---

## 🇧🇷 Português

Laboratório prático de implementação de conceitos de **Zero Trust**, cobrindo desde a descoberta de ativos até a automação de resposta a incidentes.

### Estrutura do Projeto
- `01-discovery/`: Scripts de inventário de rede (`nmap`) e escaneamento de portas para identificação de ativos e prevenção de Shadow IT.
- `02-microsegmentation/`: Arquivos Docker Compose demonstrando redes isoladas e internas para segmentação de ambientes conteinerizados.
- `03-dns-visibility/`: Diretrizes para filtragem de DNS seguro (DoH/DoT) e visibilidade de tráfego.
- `04-soar-automation/`: Scripts de resposta automatizada a incidentes (simulação de SOAR) utilizando regras de firewall.

---

## 🇬🇧 English

Hands-on laboratory for implementing **Zero Trust** concepts, covering everything from asset discovery to incident response automation.

### Project Structure
- `01-discovery/`: Network inventory scripts (`nmap`) and port scanning for asset discovery and Shadow IT prevention.
- `02-microsegmentation/`: Docker Compose files demonstrating isolated and internal networks for containerized environment segmentation.
- `03-dns-visibility/`: Guidelines for secure DNS filtering (DoH/DoT) and traffic visibility.
- `04-soar-automation/`: Automated incident response scripts (SOAR simulation) using firewall rules.
