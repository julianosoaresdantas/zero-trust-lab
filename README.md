# Zero Trust Architecture Lab

[🇧🇷 Português](#-português) | [🇬🇧 English](#-english)

## 🇧🇷 Português

Laboratório prático de implementação de conceitos de **Zero Trust**, cobrindo desde a descoberta de ativos até a automação de resposta a incidentes e monitoramento SIEM.

### Estrutura do Projeto
- `01-discovery/`: Scripts de inventário de rede (`nmap`) e escaneamento de portas.
- `02-microsegmentation/`: Redes isoladas e internas para segmentação de ambientes conteinerizados.
- `03-dns-visibility/`: Diretrizes para filtragem de DNS seguro e visibilidade de tráfego.
- `04-soar-automation/`: Scripts de resposta automatizada a incidentes (mitigação via `iptables`).
- `05-monitoring-siem/`: Coleta de logs, métricas e observabilidade de segurança.

---

## 🇬🇧 English

Hands-on laboratory for implementing **Zero Trust** concepts, covering asset discovery, microsegmentation, traffic visibility, SOAR automation, and SIEM monitoring.

### Project Structure
- `01-discovery/`: Network inventory scripts (`nmap`) and port scanning.
- `02-microsegmentation/`: Isolated and internal networks for container segmentation.
- `03-dns-visibility/`: Guidelines for secure DNS filtering and traffic visibility.
- `04-soar-automation/`: Automated incident response scripts (`iptables` mitigation).
- `05-monitoring-siem/`: Log aggregation, metrics, and security observability.
