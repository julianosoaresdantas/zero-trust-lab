# Módulo 05: Monitoramento e SIEM

Este módulo centraliza a coleta de logs de auditoria e tráfego de rede utilizando:
- **Prometheus:** Coleta de métricas de infraestrutura e status dos containers.
- **Loki:** Agregação de logs centralizada dos serviços e firewalls.
- **Grafana:** Dashboards visuais para detecção de anomalias em tempo real.
